Listen to the human test set

Every episode the scores come from, in three versions: the original TTS episode, the same lines in your voice, and (for the 16 hold episodes) your own wording of the instruction and the return cue. Each row plays sample 0 of three and shows what the scorer measured, so you can check the numbers against what you hear.

What you hear

Left channel: Moshi's generated audio. Right channel: the input (you or TTS, the friend, room noise). Each side has 30% of the other mixed in, so laptop speakers work too.

The timeline

you (outlined: own words) friend (TTS) Moshi's scripted lines Moshi speaking, generated (VAD) window the model runs freely must be silent here; dashed line = release point

How this differs from live chat

  • Outside the shaded windows, Moshi's channel is forced to the script. Each scored window starts from a clean, correct conversation, and any mistake is erased when the window ends. Live chat has no reset.
  • A window runs from the end of the instruction to about 4 s after the release, so the model never has to stay quiet or keep talking past that.
  • Timing comes from voice activity detection on the decoded audio, not from listening. Short acks within 2.5 s of the instruction are allowed.

Scores (3 samples per episode)

Score = mean of “silent when due” and “speaks when due”. The own-words column covers only the 16 hold episodes, so compare it with the TTS figure on those same episodes (in parentheses).
